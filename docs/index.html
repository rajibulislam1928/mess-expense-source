What it does

Track weekly meals and bazaar expenses in a simple Android app. Import and export your records as .xlsx files stored on your device.

The app also includes Google sign-in, group invites and manual Firebase sync controls.

Build it from source

The repository includes a Gradle 8.7 wrapper and reproducible debug-build instructions. You’ll need JDK 17 and Android SDK Platform 34 with Build-Tools 34.0.0.

git clone https://github.com/rajibulislam1928/mess-expense-source.git
cd mess-expense-source
./gradlew clean assembleDebug

Windows: use gradlew.bat clean assembleDebug. The APK is created at app/build/outputs/apk/debug/app-debug.apk.

Firebase setup and testing status

Firebase configuration is not included in the public source. To use your own Firebase project, follow the setup guide and keep google-services.json and signing credentials out of public Git.

Build 12 includes fixes for Firestore nested-array encoding and related sync payload issues; its codec regression test and build checks passed. Google sign-in on a physical phone and sync between two phones have not been verified. Local data remains saved on the device if sync fails.
